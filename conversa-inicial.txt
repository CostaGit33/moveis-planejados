# 🚀 Arquitetura Avançada — Sistema de Orçamentos com IA + Automação

## 📦 Overview Completo

Você tem um **sistema inteligente, totalmente automatizado** que:

```
👥 USUÁRIO (Telegram)
```

## 🎯 Componentes Principais

### 1️⃣ **Agent IA** (`agent-ia.js`)

**O que faz:** Processa linguagem natural e executa ações automáticas

**Ferramentas disponíveis:**

- `criar_cliente` — Cadastra novo cliente
- `criar_orcamento` — Cria orçamento com cálculos automáticos
- `listar_clientes` — Busca clientes com filtro
- `obter_orcamento` — Retorna orçamento + itens
- `listar_orcamentos` — Lista com filtro (status, cliente)
- `atualizar_orcamento` — Muda status/desconto
- `analisar_cliente` — Gera insights de cliente
- `gerar_relatorio` — Cria relatórios (faturamento, conversão, etc)

**Fluxo de execução:**

```
Mensagem do usuário
    ↓
Claude API (system prompt especializado)
    ↓
Identifica qual ferramenta chamar
    ↓
Executa ferramenta (query DB)
    ↓
Processa resultado
    ↓
Gera resposta natural + insight

```

**Exemplo de conversa:**

```
Usuário: "Quero um orçamento para João Silva com 2 portas de alumínio"

Agent:
1. Detecta: criar_orcamento + criar_cliente
2. Busca/cria cliente João Silva
3. Cria orçamento com itens
4. Calcula totais automaticamente
5. Responde: "✅ Orçamento PROP-001-2026 criado! Total: R$ 3.400,00"

```

```
Agent processa com ferramentas

```

**Exemplo de Menu:**

```
📋 Menu Principal

```

### 3️⃣ **Workflows n8n** (`n8n-workflows.json`)

**5 Workflows principais:**

#### A) **Bookipi Scraper** 🔄

**Trigger:** Cron diariamente às 22:00
**Ação:** Extrai orçamentos do Bookipi, processa com Claude, sincroniza com API

```
22:00 → Puppeteer login Bookipi
     → Navega para orçamentos
     → Extrai tabela com Cheerio
     → Claude processa dados (OCR + estruturação)
     → POST para seu banco
     → Telegram notifica admin

```

#### B) **Notificar Cliente** 💬

**Trigger:** Webhook (quando orçamento criado)
**Ação:** Envia mensagem Telegram personalizada

```
Orçamento criado (POST /webhook/orcamento-criado)
     → Claude gera mensagem personalizada
     → Telegram envia pro cliente
     → Log em DB

```

#### C) **Follow-up Automático** 📬

**Trigger:** Cron diariamente às 09:00
**Ação:** Envia lembrança para orçamentos pendentes >7 dias

```
09:00 → GET /api/orcamentos?status=enviado
     → Filtra por data (7+ dias)
     → Claude gera follow-up persuasivo
     → Envia para cada cliente via Telegram
     → Admin recebe notificação

```

#### D) **Relatório Diário** 📊

**Trigger:** Cron diariamente às 18:00
**Ação:** Calcula KPIs e envia para admin

```
18:00 → GET dados do dia
     → Calcula: total, aprovados, faturado, taxa conversão
     → Formata mensagem elegante
     → Envia via Telegram

```

#### E) **Detecção de Anomalias** 🚨

**Trigger:** Cron a cada 2 horas
**Ação:** Claude analisa padrões anormais

```
A cada 2h → GET últimos 50 orçamentos
         → Claude analisa anomalias
         → Se houver: alerta admin via Telegram
         → Identifica: valores outlier, taxa conversão anormal, etc

```

#### F) **Export Excel Mensal** 📥

**Trigger:** Cron último dia do mês às 23:00
**Ação:** Cria relatório em Excel e envia por email

```
Último dia às 23:00 → GET todos os orçamentos do mês
                   → Gera planilha com dados + resumo
                   → Email para admin

```

### 4️⃣ **API Node.js** (`server.js`)

**Endpoints core:**

| Método Rota Descrição  |                                      |                  |
| ---------------------- | ------------------------------------ | ---------------- |
| GET                    | `/api/clientes`                      | Lista clientes   |
| POST                   | `/api/clientes`                      | Cria cliente     |
| GET                    | `/api/orcamentos`                    | Lista orçamentos |
| POST                   | `/api/orcamentos`                    | Cria orçamento   |
| GET                    | `/api/orcamentos/:id`                | Obter completo   |
| PUT                    | `/api/orcamentos/:id`                | Atualizar        |
| POST                   | `/api/orcamentos/:id/itens`          | Adicionar item   |
| DELETE                 | `/api/orcamentos/:id/itens/:item_id` | Remover item     |

**Especial:** Webhook para notificações

```
POST /webhook/orcamento-criado → n8n processa

```

## 🛠️ Setup Completo (Passo a Passo)

### Pré-requisitos:

- Node.js 16+
- PostgreSQL
- Conta n8n (self-hosted ou cloud)
- Conta Telegram Bot (@BotFather)
- API Key Anthropic (Claude)

### 1️⃣ Backend + DB

```bash
# Criar pasta
mkdir orcamentos-ia && cd orcamentos-ia

# Clone schema
psql -U postgres -d orcamentos_moveis -f orcamento_moveis_schema.sql

# Instalar dependências
npm init -y
npm install express pg cors body-parser dotenv telegraf @anthropic-ai/sdk

# Copiar arquivos

# Criar .env
cat > .env << EOF
DB_USER=seu_user
DB_PASSWORD=sua_senha

TELEGRAM_BOT_TOKEN=seu_token

ANTHROPIC_API_KEY=sua_key
API_URL=http://localhost:3000

BOOKIPI_USER=seu_email
BOOKIPI_PASSWORD=sua_senha
EOF

# Iniciar
npm install -g nodemon
npm start

```

```
   ↓
Agent identifica:
- Cliente: Maria
- Itens: 3 portas, 2 kits

```

## 📊 Métricas & KPIs

### Calculados em Tempo Real:

| KPI Fórmula Ação           |                                           |                     |
| -------------------------- | ----------------------------------------- | ------------------- |
| **Faturado**               | SUM(valor\_total) WHERE status=finalizado | 💰 Revenue tracking |
| **Pendente**               | SUM(valor\_total) WHERE status=aprovado   | ⏱️ Cash flow        |
| **Taxa Conversão**         | (aprovados+finalizados) / total \* 100    | 📈 Performance      |
| **Ticket Médio**           | faturado / finalizados                    | 🎯 AOV              |
| **Taxa Rejeição**          | rejeitados / total \* 100                 | ⚠️ Preço?           |
| **Cliente Lifetime Value** | SUM(valor) por cliente                    | ⭐ Segmentação       |

### Recomendações Automáticas:

- ✅ Taxa >70% → "Mantenha esse padrão!"
- 🔴 Taxa <30% → "Revise follow-up"
- ⭐ Cliente >10K → "Ofereça desconto"
- 📈 Pendente >50% → "Priorize conversão"
- ⚠️ Rejeição >20% → "Revise preços"

```bash

curl https://api.telegram.org/bot{TOKEN}/getMe

# Verificar logs
pm2 logs telegram-bot

```

### n8n workflows não executam?

```bash
# Verificar credenciais
# Verificar cron expression (https://crontab.guru)
# Logs: Dashboard n8n

```

### Agent IA não funciona?

```bash
# Testar API
curl https://api.anthropic.com/v1/messages \
  -H "Authorization: Bearer $ANTHROPIC_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{...}'

```

### Dashboard lento?

```javascript
// Adicionar cache
const cache = new Map();
setInterval(() => cache.clear(), 5 * 60 * 1000); // 5 min

// Ou usar Redis

```
